## 📖 About The Project

**OLED Display Code** is an open-source Arduino project featuring a collection of creative animations and visual effects designed for OLED displays.

From expressive animated robot eyes to music visualizers, digital effects and mini-games, this repository brings small OLED screens to life.

Whether you're an Arduino enthusiast, robotics developer, electronics hobbyist or maker, you can explore, modify and build your own OLED animation projects.

## ✨ Features

- 🤖 Animated Robot Eyes with multiple emotions.
- 🎵 Spotify-style Music Equalizer.
- 🎶 Typewriter and Scrolling Lyrics.
- ⚽ Bouncing Ball Animation.
- 📊 Audio Waveform Visualizer.
- ❤️ Heartbeat Animation.
- 😴 Sleepy, Angry, Happy, Sad and Surprised Eyes.
- ✨ Floating Particle Effects.
- 🔄 Circular Loading Animation.
- 👾 Digital Glitch Effects.
- 🎮 Mini OLED Games.
- 💻 Mini Hacker Console.
- 🎨 Multiple animation collections.

## 🛠️ Hardware Requirements

- Arduino UNO / Nano / ESP32 (depending on sketch compatibility).
- SSD1306 OLED Display (commonly 128×64).
- USB Cable.
- Jumper Wires.
- Breadboard (optional).

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/satyamshorrf/OLED-display-code.git
```

### 2. Open Arduino IDE

Download and install the Arduino IDE:

https://www.arduino.cc/en/software

### 3. Select an Animation

Open any `.ino` file from the repository.

### 4. Install Required Libraries

Install the libraries required by the selected sketch through Arduino IDE Library Manager.

Common OLED libraries include:

- Adafruit GFX Library
- Adafruit SSD1306
- U8g2 (if required by a particular sketch)

### 5. Upload

Select your board and COM port, then click **Upload**.

Enjoy your OLED animations! 🚀

> Note: Pin configurations, display addresses and library requirements may vary between sketches. Check the individual source code before uploading.

## 🔌 Typical OLED Connections

| OLED Display | Arduino UNO |
|---|---|
| VCC | 5V (if supported by module) |
| GND | GND |
| SDA | A4 |
| SCL | A5 |
